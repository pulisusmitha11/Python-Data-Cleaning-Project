# Python Data Cleaning Project

## Project Description
This project cleans student data using Python and Pandas.

## Features
- Identifies missing values
- Fills missing values
- Removes duplicate records
- Saves cleaned data into an Excel file
- Creates a student marks bar chart

## Technologies Used
- Python
- Pandas
- Matplotlib
- OpenPyXL

## How to Run
Run the following command in the terminal:

`python data_cleaning.py`

## Output
The project displays cleaned student data, generates a marks chart, and saves the results in an Excel file.
